# Расенган × Чидори

Веб-камера следит за руками: на правой ладони появляется Расенган, на левой — Чидори.
Кулак гасит технику, сведённые заряженные руки дают столкновение.
На лбу — повязка Конохи; с Чидори она перечёркнута, как у Саске, и рядом облако Акацуки.

**Открыть:** https://abduzoirmu-rgb.github.io/rasengan-chidori/

Камера спросит разрешение один раз. Всё считается прямо в браузере, видео никуда не отправляется.
Распознавание рук — [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) (Apache 2.0), модель вшита в `index.html`.
